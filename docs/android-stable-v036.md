## 构建与签名

功能分支生成 unsigned release APK，构建工具 apksigner.jar 作为中间产物。使用 tools/sign-personal-apk.mjs 在本机签名并验证：需提供输入包、输出包、apksigner.jar 路径，RIXU_JAVA_HOME 和 RIXU_SIGNING_DIR 环境变量。

第一次生成加密 PKCS12 密钥及随机密码文件，以后复用；脚本发现密钥与密码只有其一会拒绝生成替代身份。私有目录必须单独安全备份，不放 GitHub、公开制品或聊天。未来换电脑/会话先恢复这套身份，不能重新生成密钥顶替。

签名后验签、记录公开证书指纹与 APK SHA256。发布之前应验证两次构建证书一致、版本号递增。固定签名不代替数据库迁移和备份保护。自动化通过不等于真实手机声音、振动或跨版本安装验收。
