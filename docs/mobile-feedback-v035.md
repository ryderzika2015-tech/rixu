# 安卓真机反馈修复

用户设备为华为 Pura 70 Pro+ / HarmonyOS 4.2.0，本轮明确优先处理真机反馈。

- 每条事项使用一个提醒时间，默认每隔 15 分钟共 3 次，可选择 1–5 次、10–120 分钟；选择不再提醒可停止。旧开始/结束/截止字段保留存储兼容，不清除历史记录，新界面不再要求理解多个时间概念。
- 新提醒时间 at 为可选字段，旧备份不变更 schema，旧规则继续兼容。备忘保存时其提醒时间也是截止时间。
- 系统通知交给 Capacitor Local Notifications 安排，最多 500 条；差量更新，不取消其他用途通知。通知与前台弹窗均提供继续/停止。通知按钮会打开应用执行停止并保存状态，不宣称无需唤起应用即可在原生端持久化停止。
- 用户必须在设置中开启通知并允许精确闹钟。未授权与安排失败会展示状态，不宣称已就绪。划掉应用后由系统已安排的闹钟触发，不依赖 JS 轮询；系统强行停止、电池管理限制、关闭锁屏通知等场景仍需华为真机验收，不能保证强行停止后提醒。
- 修复中文月日、空格、中文数词、早晚、全角冒号、AM/PM 等时间解析；非法日期/时间和过期时间继续待确认，不任意推到明天。未支持的模糊表达仍需人工确认。
- 新建录入保留显式任务/备忘类型，不再只按日期推断。同日备忘显示在备忘分组，编辑器可手动纠正旧记录类型，不自动迁移既有记录。
- 今日计划直接左右滑动逐条查看，保留全部列表入口。

## 安装与验收

旧首包签名未固定。本次为避免覆盖失败后误删数据，使用独立应用 ID tech.rixu.personal.reminders，显示“日序·提醒版”，与旧日序共存。旧版原地保留；新旧两应用本地数据独立，请先从旧版导出外部 JSON 备份，再主动导入新版。不要卸载旧版来尝试覆盖更新。长期统一包名和私有签名仍待独立处理。

1. 开启通知、锁屏显示和精确闹钟，按华为手机实际情况允许后台运行；确认设置显示系统提醒已就绪。
2. 建立几分钟后首次提醒的测试事项，默认 15 分钟重复 3 次，划掉应用并锁屏，观察系统通知；继续应保留剩余次数，停止后不再触发。
3. 修改提醒时间、完成或删除事项，确认原通知取消；重新打开应用核对安排状态。手机重启后是否恢复也需实测。
4. 用截图中的彩排与今晚 11 点示例验证；选择备忘后保存，确认位于备忘分组。同日备忘不计入今日任务卡片，但原领域任务视图仍保留到期事项兼容行为。
5. 左右滑动今日白色内容卡片，确认可访问每条任务，点击完成、编辑和专注仍可操作；待真机确认手势和可读性。

本轮不改生产站、Neon 或 Worker 配置，不开启同步，不发布商店。自动化、APK 编译与真机通知验收必须分别记录。
