# 安卓个人版首包

目标：不依赖云账号，先在安卓手机验收本地计划、账本、专注与备份。网站和云端配置不变，不合并 main，不发布商店。

## 构建

需要 Node >=22.12、JDK 21、Android SDK 36。运行 npm ci、npm run android:prepare，然后在 android 目录运行 ./gradlew assembleDebug（Windows 使用 gradlew.bat）。Android 工程由固定版本 Capacitor 生成，不提交编译目录；重复 prepare 会重新同步网页资产。

GitHub 功能分支 codex/android-personal-v034 的推送触发 Android personal APK，成功后在运行的 Artifacts 下载 rixu-personal-debug-apk，解压获得 app-debug.apk。

这是调试验收包，非长期签名版本。不同构建机生成的签名可能不同，后续不能保证覆盖安装；开始长期使用前应配置稳定的私有签名。不要卸载现有应用来解决安装冲突，先另存 JSON 备份。

## 手机安装与数据

1. 首次安装仅为传送 APK 的文件管理器或浏览器临时允许“安装未知应用”，安装后可关闭。
2. 无需登录。首次打开可见预置计划；自行新增一条测试任务和一笔测试支出，结束进程后重开，验证数据仍在。
3. 电脑日序的设置中导出 JSON 备份，私下传到手机。手机设置的备份与恢复中选择该文件，先检查预览数量，再主动选择合并或覆盖。覆盖前有应用内恢复副本，但仍应保留外部备份。
4. 手机导出通过系统分享菜单，请选择能保存文件的位置或个人接收应用。打开分享菜单不等于已在应用外另存；应确认文件已收到并能重新导入。
5. 在断网时测试新增、编辑、专注及重开；在临时测试数据上验证导出后再次导入，不能用真实数据做破坏性试验。

## 当前边界

- Android 最低版本为 7.0 / API 24，仍需要可用的系统 WebView；不是 Google 账号登录，不要求安装 Google Play 服务。
- 本地存储暂用应用私有 WebView 的 IndexedDB，SQLite 迁移后续再做。卸载、清除应用数据会删除本地记录。
- Android 自动备份已关闭；只有用户主动导出分享的数据才离开应用。
- 没有手机与电脑同步、系统锁屏通知、语音能力保证。严格专注模式仍在应用隐藏时暂停。
- 不向 APK 注入 Neon Auth 或 Worker 地址，不在 APK 中打包密码、JWT、数据库凭据或私人记录。
- APK 的生成不等于已通过真机验收，应按上述步骤测试后再决定长期使用。
