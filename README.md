# 日序 0.3.2｜源码修复版

该工程延续 V2.2 的简洁界面，采用 Vue 3 + TypeScript。0.3.2 重点修复智能记账、专注时间统计、长周期复盘及提醒规则。

## Windows 安装运行

1. **先备份真实数据**：从旧日序导出备份，旧版文件不要删除；不要清理浏览器存储。
2. 关闭旧开发服务器（旧终端中按 Ctrl+C）。
3. 解压完整 `rixu-app` 文件夹。在该文件夹地址栏输入 `cmd` 打开命令行。
4. 运行：

```bat
npm.cmd install
npm.cmd run dev -- --port 4173 --strictPort
```

5. 打开 `http://127.0.0.1:4173/`。如使用同一浏览器和相同地址，原来的本地数据应保持可用；**任何迁移前仍建议另存独立 JSON 备份**。
6. 验证后再运行 `npm.cmd run build` 生成生产网站资源。

### 无法安装 npm 时的临时预览

包内 `dist` 带有离线构建的预览资源。可以运行 `node tools/serve.mjs` 访问同一地址。请注意：这个 dist 是受限环境的**离线编译产物，不是正式 Vite 构建**。正式部署前必须在可联网环境使用上述 npm/Vite 流程验证并重建。

## V0.3.2 修复清单

- **记账**：识别“我吃饭花了八元”等中文数字金额；候选记录可编辑金额、日期、分类、类型、名称、标签。没有金额不再直接入账，可以手动补齐。
- **保存语义**：“暂存草稿”只进入待确认收件箱；“正式保存”仅把选中的有效候选写入账本/任务。金额未补齐的内容不会被暗中当作正式支出。
- **专注**：学习模式返回首页仍计时；严格模式返回专注页之外或页面隐藏时暂停。计时未结束、任务未完成时，当前有效时间也参与复盘统计；低于 1 分钟显示秒数。
- **复盘**：月、季度、半年、年及自定义范围的任务、时间、收支统计与本地文字分析；云端 AI 未接入，不虚构 AI 输出。
- **提醒**：远期提前天数、临近提前小时、最多提醒次数、重复间隔，以及单任务稍后 15/60 分钟、停止、恢复。网页前台运行时展示小型应用内提醒；**安卓后台/锁屏系统通知尚未接入**。

## 注意

- **目前没有**账号、云同步、云端 AI、Android APK 或系统级后台提醒。
- 浏览器语音识别能力受环境影响，输入文本与解析预览可离线使用。
- 不要提交真实私人备份、账本数据、API Key 至公开仓库。
- `package.json` 已固定 Vue `3.5.45`。本环境无法连接 npm 注册表完成正式在线依赖安装；用户 Windows 环境曾成功安装 Vue 3.5.45 和 Vite，可以继续用 npm 构建。
